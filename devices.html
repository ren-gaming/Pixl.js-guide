Pixl.js Amiibo emulator

A small Bluetooth device with a screen that can act as an Amiibo. This page covers what is on it, what to set up first, and how updates work.

What it is

The Pixl.js Amiibo firmware turns a small NFC and Bluetooth device into an Amiibo emulator. You pick an Amiibo on the device, then hold it to a game or console that reads Amiibo.

Two different things share the name. The original Pixl.js is a general-purpose device that runs Espruino. The Amiibo emulator described here is a separate project by solosky with its own firmware and hardware. If you search for help, check that the guide you find is for the Amiibo firmware, because the update steps are different.

Apps on the device

The firmware is organised as a menu of small apps. The project documentation lists these:

  • Amiibo EmulatorPick an Amiibo and emulate it
  • Amiibo DatabaseBrowse and search a built-in library
  • AmiiboLink EmulatorWork with AmiiboLink over Bluetooth
  • Card EmulatorEmulate other NFC cards
  • BLE File TransferSend files to the device over Bluetooth
  • SettingsConfigure the device

Illustration of the idea. Your device's menu may look different and can change between firmware versions.

Before you start

Some features need a file called key_retail.bin on the device's storage. The project documentation says it has to be a copy you obtained legally, for example from your own console, and that it goes in the root of the device storage. Without it, those features will not work.

Only use files you have the right to use. The project does not supply this key, and neither does this page.

Updating firmware

The first install of the firmware on blank hardware needs a hardware programmer such as a J-Link or DAPLink. Most devices arrive with it already installed. After that, updates can be sent over the air.

  • Put the device into its update (DFU) mode, then use nRF Connect or the project's web page to send the new firmware. The Mochi web page below can also do this for you.
  • On iOS, the release notes recommend the iNFC or MTools BLE apps for one-tap updates.
  • Download firmware only from the project's releases page, and read the notes for each version before updating. Some releases are bug-fix versions.

How to enter update mode depends on your hardware, so follow the flashing guide in the project documentation rather than a generic one.

Add Amiibo and update firmware with Mochi

Mochi is a web page made by someone else that connects to the device over Bluetooth, so you can manage its files and update its firmware from a browser. There is nothing to install.

Open Mochi

  • Connect: turn on Bluetooth, open the page in Chrome or Edge, and choose Connect device.
  • Add Amiibo: drag files or folders onto the page, or click to choose them. They go into a queue, and you start the transfer when you are ready. You can also compare a folder with what is already on the device.
  • Update firmware: open Actions, choose Update firmware, and pick your model (the white LCD version or the black OLED version). Mochi downloads the matching official firmware for you, or you can pick your own .zip file.

Take care with two actions. If an update is interrupted, the device can stay in update mode. Mochi says you can fix this by retrying with the correct file. The Actions menu also has a Format drive option, so check before you use it.

Mochi is not part of the Pixl.js project and is not maintained by this site. Check that it works with your device before relying on it.
